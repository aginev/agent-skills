## [0.1.0] - 2026-07-09

### Added

- `critically-evaluate` skill: get an adversarial second opinion on a design doc, ADR, RFC, spec, or plan by running OpenAI's Codex CLI against it, then having Claude critically review Codex's feedback point by point.
- `README.md` documenting the agent skills structure, available skills, installation via `npx skills add aginev/agent-skills`, and instructions for adding new skills.
- MIT `LICENSE`.
- `.gitignore` to exclude unnecessary files and directories.
